How to Open FolioSort on Windows

FolioSort isn't code-signed yet, so Windows Defender SmartScreen
will warn you on the first launch. It is not a virus — here's how to open it.

Recommended

Fastest SmartScreen → More info → Run anyway

Takes 10 seconds. Windows only asks once per executable.

Windows 10 & 11 (x64)
1 Right-click the downloaded FolioSort-2.18.0-windows.zip → Properties → at the bottom tick Unblock → OK. (Skips re-prompting on every extracted file.)
2 Right-click the zip → Extract All… and pick a folder you own, e.g. C:\Users\<you>\Apps\FolioSort\. Keep FolioSort.exe and Resources\ together.
3 Double-click FolioSort.exe. The blue SmartScreen dialog appears:
Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

▸ More info

4 Click More info. A Run anyway button appears at the bottom — click it.
5 Done — FolioSort launches. Future opens go straight to the app, no prompt.
Why does Windows do this? SmartScreen flags every new executable that doesn't have a paid Microsoft code-signing certificate — even open-source apps with public source code (like this one). Once you've clicked Run anyway, Windows remembers the choice for that exact file.

If Your Antivirus Quarantined It

If blocked Norton / McAfee / Avast Heuristic

Some AV suites quarantine self-contained .NET single-file executables.

Windows 10 & 11 (x64)
1 Open your antivirus dashboard → Quarantine / History.
2 Locate FolioSort.exe, click Restore (or Trust / Allow).
3 Add an exclusion for the install folder so future updates aren't flagged.
Why does this happen? Heuristic engines flag the AOT / single-file packaging pattern itself, not the app's behavior. The same warning fires for any .NET 8 single-file build that bundles its runtime. The source for FolioSort is public on GitHub — every release is reproducible.

1 Delete the folder you extracted to (the one containing FolioSort.exe).
2 Open File Explorer's address bar and paste: %LOCALAPPDATA%\FolioSort → press Enter → delete that folder too (settings, license, undo history).
Troubleshooting — still won't open?

1. The zip didn't extract cleanly.
FolioSort needs FolioSort.exe and the Resources\ folder in the same directory. Re-extract the zip with right-click → Extract All; don't drag individual files out.

2. "VCRUNTIME140.dll is missing" or similar.
You'll need the Microsoft Visual C++ Redistributable (x64). The .NET 8 runtime is bundled inside FolioSort.exe, so a separate .NET install is not required.

3. Group Policy / Enterprise / Work laptop:
Your IT department may have an AppLocker / WDAC policy that blocks unsigned executables outright. There's nothing the app can do — ask IT to whitelist the FolioSort folder or run it from your personal device.

4. Re-download the zip:
Occasionally a download is truncated. Re-download from the releases page and compare the file size with what's listed there.
